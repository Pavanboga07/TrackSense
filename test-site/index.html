Tracker v2.1 — New Features

🎯 Goal Tracking — data-si-goal attribute

These buttons emit a goal_triggered event on click — the definitive conversion signal the AI uses. Each event carries the full journey (which pages the user visited before clicking) and css_path so the element is unambiguously identified.

Each goal_triggered event includes: goal_name, goal_value, css_path, time_on_page_ms, and journey[] (the last 10 steps the user took before converting).

👤 User Identification — SI.identify()

Ties all subsequent events to a real user. Stored in localStorage across sessions.

No user identified.

🧪 A/B Test Variants — SI.setVariant()

Set once; variant auto-attaches to every subsequent event as metadata.variant_*.

👁 Element Visibility — data-si-track & SI.trackElement()

These elements fire element_viewed when they scroll into view (once per load).

🏷 data-si-track="pricing_section_cta"
🏷 data-si-track="footer_signup_banner"

🔗 Outbound Click Tracking

Clicks on external links auto-fire outbound_click with the destination URL.

🎬 Video Tracking — auto-tracked on all <video> elements

Play/pause/complete events fire automatically with current_time and percent_watched.

🐛 Error Tracking — auto-captured js_error events

Runtime errors and unhandled rejections are captured automatically with stack traces.

😤 Rage Click Detection
